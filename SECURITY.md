# Security policy

This is a local learning project, not a hosted production service. It does not include HTTPS termination, rate limiting, password recovery, or production operations. Do not expose the local server directly to the internet or use real credentials.

If you find a vulnerability, please use GitHub's **Report a vulnerability** option on the repository's Security tab. Include reproduction steps and the affected code. Please avoid opening a public issue until the maintainer has had a chance to review the report.

The project does not offer a fixed response or disclosure timeline. The maintainer will review reports as availability permits.
