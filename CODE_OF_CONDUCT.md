# Community guidelines

This project welcomes contributors of different experience levels. Keep discussion respectful, specific, and useful to the work.

- Assume good intent and discuss code or behavior without personal attacks.
- Give constructive feedback and make room for questions.
- Do not post harassment, discriminatory language, private information, or spam.

Maintainers may edit or remove comments and close issues or pull requests that violate these guidelines. If you encounter a problem, contact the repository owner through GitHub rather than continuing a hostile public exchange. Security reports should follow [SECURITY.md](SECURITY.md).
